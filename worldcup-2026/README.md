# 🏆 2026 FIFA 世界杯数据库

> 48支球队 · 72场小组赛 · 完整预测追踪系统

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `worldcup_2026.db` | SQLite 数据库文件（32KB） |
| `worldcup_2026_dump.sql` | 完整SQL导出（可直接导入任意SQL数据库） |
| `query.py` | Python 查询脚本（命令行工具） |

## 📊 数据结构

### teams 表（48支球队）
- 队名、FIFA排名、身价（百万欧元）
- 分组、主教练、核心球员
- 近期状态

### matches 表（72场小组赛）
- 比赛编号、主客队、分组、时间、场地
- 市场概率（主胜/平/客胜）、大小球线
- 双方排名、身价
- 预测比分、信心等级（1-5星）
- 赛后实际结果

### predictions 表
- 赛后追踪预测准确率

## 🚀 快速使用

```bash
# 导入数据库
sqlite3 worldcup_2026.db < worldcup_2026_dump.sql

# 使用查询脚本
python3 query.py standings    # 积分榜
python3 query.py today        # 今日比赛
python3 query.py predict      # 我的预测汇总
python3 query.py team 巴西    # 查询球队
```
